Quick Web Notepad: a free, private notepad in your browser

Quick Web Notepad is a free, open-source notepad that runs entirely in your web browser. You can write plain text, open and save files on your device, find and replace with regular expressions, and preview Markdown. It needs no account, your notes are not uploaded to a server, and after your first visit it also works offline.

Open the notepad

Features

  • Plain-text editing with word count, character count and cursor position.
  • Open and save text files on your device, or drop a file on the page to open it.
  • Find and replace, with match case and regular expressions.
  • Syntax view: read-only highlighting for JavaScript, Python, HTML, CSS, JSON, SQL, shell, C and Markdown.
  • Markdown view: a read-only rendered preview with tables, task lists and code blocks. The Markdown viewer opens files straight in this view.
  • Lock mode, which protects the text from accidental edits.
  • Recent notes: notes from closed tabs can be reopened from the toolbar.
  • Light and dark themes, zoom and word wrap.
  • Installable as an app, and usable without an internet connection.
  • An interface in 15 languages.

Where your notes are stored

Your text stays on your device. While you type, the text and file name of the current tab are copied to that tab's sessionStorage so they survive an accidental reload, and a new tab always starts empty. A copy of each note is also kept in the browser's localStorage, so after you close a tab its note is listed under Recent in the toolbar, where you can reopen it or delete it. Up to 30 notes are kept; you can turn this off in the same menu. Your theme, language, zoom and word-wrap preferences are kept in localStorage too. Nothing is synced between devices, so to keep a note for good, save it to a file with Ctrl+S. The privacy policy has the details.

Opening and saving files

Ctrl+O opens a text file from your device and Ctrl+S saves it. In Chrome, Edge and other Chromium-based desktop browsers, saving writes back to the file you opened, after the browser asks for permission. In browsers without that feature, such as Firefox and Safari, saving downloads a copy.

Markdown preview and syntax view

The Markdown view (Alt+M) renders the note as a formatted document. It supports GitHub Flavored Markdown: tables, task lists and fenced code blocks with highlighting. The preview is rendered on your device and the generated HTML is sanitized. If a note embeds an image from another website, your browser requests that image from that website.

The Syntax view (Ctrl+Shift+H) colors code in JavaScript, Python, HTML, CSS, JSON, SQL, shell, C and Markdown. The language is detected from the file extension or from the content. Both views are read-only: the text is locked while a view is open, and unlocking returns to editing.

Find and replace

Ctrl+F opens the find bar. You can match case, search with a regular expression, replace one match or replace all. Enter moves to the next match and Shift+Enter to the previous one. In the Syntax and Markdown views the search runs over the displayed text and highlights the matches.

Lock mode

Ctrl+Shift+L locks the text so that typing, pasting, replacing and clearing are blocked until you unlock it. Pressing Esc three times while locked unlocks and clears the text.

Offline use and installing the app

After your first visit the browser keeps a copy of the app, so it opens without an internet connection. In Chrome and Edge you can install it from the install option in the address bar or the browser menu. On iPhone and iPad, use Share and then Add to Home Screen.

Limitations

  • No sync, cloud backup or sharing by link.
  • One document per tab. Closed notes are kept only in this browser, up to 30 of them.
  • The Syntax and Markdown views are for reading, not for editing.
  • It needs a modern browser with JavaScript enabled.

Frequently asked questions

Is Quick Web Notepad free?

Yes. It is free to use, there is no paid tier, and the source code is published under the MIT license. The site shows ads from Google AdSense, including one thin strip under the editor.

Do I need an account?

No. There is no sign-up and no login.

Are my notes uploaded or stored on a server?

No. The app has no backend. Your text is processed in your browser and stays on your device.

What happens to my text when I close the tab?

It stays on this device. Closed notes are listed under Recent, where you can reopen or delete them; a new tab still starts empty. Nothing is synced to other devices, so to keep a note for good, save it as a file with Ctrl+S.

Does it work offline?

Yes. After your first visit the app is cached by the browser and opens without an internet connection. It can also be installed like an app from the browser's install option.

Can it save back to the same file?

Yes, in browsers that support the File System Access API, such as Chrome and Edge on desktop. In other browsers, such as Firefox and Safari, saving downloads a copy of the file.

Can it preview Markdown?

Yes. Press Alt+M or the Markdown button for a read-only preview with tables, task lists and highlighted code blocks. The preview is rendered on your device. To read .md files, the Markdown viewer shows each file you open, drop or paste formatted right away.

Is it like Windows Notepad?

Yes, in the essentials: plain text, opening and saving .txt files, and find and replace. It runs in the browser, so it works on any system without installing anything, and it adds a dark theme, a Markdown preview and syntax highlighting.

Does it work on phones and tablets?

Yes. On small screens the toolbar shows icons only and wraps onto more than one line.

Which languages is the interface available in?

English, Spanish, Chinese, Hindi, Arabic, French, Portuguese, Indonesian, Vietnamese, Turkish, Thai, German, Japanese, Korean and Russian.

Who makes it

Quick Web Notepad is created by OFCode-dev as a small independent web tool. It is built with plain HTML, CSS and JavaScript, without a framework or a build step. The Markdown view uses the open-source libraries marked and DOMPurify, which are served from this site. The source code is on GitHub under the MIT license.
