Quick Web Notepad: um bloco de notas online grátis e privado no seu navegador

O Quick Web Notepad é um bloco de notas grátis e de código aberto que roda inteiramente no seu navegador. Você pode escrever texto simples, abrir e salvar arquivos no seu dispositivo, localizar e substituir com expressões regulares e visualizar Markdown. Não precisa de conta, suas notas não são enviadas a nenhum servidor e, depois da primeira visita, ele também funciona offline.

Recursos

  • Edição de texto simples com contagem de palavras, contagem de caracteres e posição do cursor.
  • Abra e salve arquivos de texto no seu dispositivo, ou solte um arquivo na página para abri-lo.
  • Localizar e substituir, com diferenciação de maiúsculas e minúsculas e expressões regulares.
  • Sintaxe: realce somente leitura para JavaScript, Python, HTML, CSS, JSON, SQL, shell, C e Markdown.
  • Markdown: uma prévia formatada somente leitura, com tabelas, listas de tarefas e blocos de código. O visualizador de Markdown abre os arquivos direto nessa visualização.
  • Modo de bloqueio, que protege o texto contra edições acidentais.
  • Recentes: as notas de abas fechadas podem ser reabertas pela barra de ferramentas.
  • Temas claro e escuro, zoom e quebra de linha.
  • Pode ser instalado como aplicativo e usado sem conexão com a internet.
  • Interface em 15 idiomas.

Onde ficam suas notas

Seu texto fica no seu dispositivo. Enquanto você digita, o texto e o nome do arquivo da aba atual são copiados para o sessionStorage dessa aba, para sobreviverem a um recarregamento acidental, e uma nova aba sempre começa vazia. Uma cópia de cada nota também fica no localStorage do navegador; assim, depois que você fecha uma aba, a nota aparece em Recentes na barra de ferramentas, onde é possível reabri-la ou excluí-la. São guardadas até 30 notas, e você pode desativar isso no mesmo menu. As preferências de tema, idioma, zoom e quebra de linha também ficam no localStorage. Nada é sincronizado entre dispositivos; para guardar uma nota de vez, salve-a em um arquivo com Ctrl+S. A política de privacidade (em inglês) traz os detalhes.

Abrir e salvar arquivos

Ctrl+O abre um arquivo de texto do seu dispositivo e Ctrl+S o salva. No Chrome, no Edge e em outros navegadores para computador baseados no Chromium, salvar grava de volta no arquivo que você abriu, depois que o navegador pede permissão. Em navegadores sem esse recurso, como Firefox e Safari, salvar baixa uma cópia.

Prévia de Markdown e realce de sintaxe

A visualização Markdown (Alt+M) mostra a nota como um documento formatado. Ela é compatível com o GitHub Flavored Markdown: tabelas, listas de tarefas e blocos de código cercados, com realce. A prévia é gerada no seu dispositivo e o HTML resultante é sanitizado. Se uma nota incorporar uma imagem de outro site, o navegador solicita essa imagem a esse site.

A visualização Sintaxe (Ctrl+Shift+H) colore código em JavaScript, Python, HTML, CSS, JSON, SQL, shell, C e Markdown. A linguagem é detectada pela extensão do arquivo ou pelo conteúdo. As duas visualizações são somente leitura: o texto fica bloqueado enquanto uma delas está aberta, e desbloquear volta à edição.

Localizar e substituir

Ctrl+F abre a barra de busca. Você pode diferenciar maiúsculas e minúsculas, buscar com uma expressão regular, substituir uma ocorrência ou substituir todas. Enter vai para a próxima ocorrência e Shift+Enter para a anterior. Nas visualizações Sintaxe e Markdown, a busca percorre o texto exibido e destaca as ocorrências.

Modo de bloqueio

Ctrl+Shift+L bloqueia o texto: digitar, colar, substituir e limpar ficam impedidos até você desbloquear. Pressionar Esc três vezes com o texto bloqueado desbloqueia e limpa o texto.

Uso offline e instalação

Depois da primeira visita, o navegador guarda uma cópia do aplicativo, então ele abre sem conexão com a internet. No Chrome e no Edge, você pode instalá-lo pela opção de instalação na barra de endereços ou no menu do navegador. No iPhone e no iPad, use Compartilhar e depois Adicionar à Tela de Início.

Limitações

  • Sem sincronização, backup na nuvem ou compartilhamento por link.
  • Um documento por aba. As notas fechadas ficam só neste navegador, até 30.
  • As visualizações Sintaxe e Markdown servem para ler, não para editar.
  • Exige um navegador moderno com JavaScript ativado.

Perguntas frequentes

O Quick Web Notepad é grátis?

Sim. O uso é gratuito, não há plano pago e o código-fonte é publicado sob a licença MIT. O site exibe anúncios do Google AdSense, incluindo uma faixa fina abaixo do editor.

Preciso criar uma conta?

Não. Não há cadastro nem login.

Minhas notas são enviadas ou guardadas em um servidor?

Não. O aplicativo funciona sem servidor: seu texto é processado no navegador e fica no seu dispositivo.

O que acontece com o meu texto quando fecho a aba?

Ele continua neste dispositivo. As notas fechadas aparecem em Recentes, onde você pode reabri-las ou excluí-las; uma nova aba continua começando vazia. Nada é sincronizado com outros dispositivos; para guardar uma nota de vez, salve-a em um arquivo com Ctrl+S.

Funciona offline?

Sim. Depois da primeira visita, o navegador guarda o aplicativo em cache e ele abre sem conexão com a internet. Também é possível instalá-lo como aplicativo pela opção de instalação do navegador.

Dá para salvar no mesmo arquivo?

Sim, nos navegadores compatíveis com a File System Access API, como Chrome e Edge para computador. Em outros navegadores, como Firefox e Safari, salvar baixa uma cópia do arquivo.

Tem prévia de Markdown?

Sim. Pressione Alt+M ou o botão Markdown para ver uma prévia somente leitura com tabelas, listas de tarefas e blocos de código com realce. A prévia é gerada no seu dispositivo. Para ler arquivos .md, o visualizador de Markdown mostra formatado na hora cada arquivo que você abre, solta ou cola.

É parecido com o Bloco de Notas do Windows?

Sim, no essencial: texto simples, abrir e salvar arquivos .txt e localizar e substituir. Ele roda no navegador, então funciona em qualquer sistema sem instalar nada, e acrescenta tema escuro, prévia de Markdown e realce de sintaxe.

Funciona em celulares e tablets?

Sim. Em telas pequenas, a barra de ferramentas mostra apenas ícones e se divide em mais de uma linha.

Em quais idiomas a interface está disponível?

Inglês, espanhol, chinês, hindi, árabe, francês, português, indonésio, vietnamita, turco, tailandês, alemão, japonês, coreano e russo.

Quem desenvolve

O Quick Web Notepad é criado pela OFCode-dev como uma pequena ferramenta web independente. Ele é feito com HTML, CSS e JavaScript puros, sem framework nem etapa de build. A visualização Markdown usa as bibliotecas de código aberto marked e DOMPurify, servidas por este site. O código-fonte está no GitHub sob a licença MIT.
