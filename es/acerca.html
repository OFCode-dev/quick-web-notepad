Quick Web Notepad: un bloc de notas online gratis y privado en tu navegador

Quick Web Notepad es un bloc de notas gratis y de código abierto que funciona por completo en tu navegador. Puedes escribir texto sin formato, abrir y guardar archivos en tu dispositivo, buscar y reemplazar con expresiones regulares y previsualizar Markdown. No necesita cuenta, tus notas no se suben a ningún servidor y, después de la primera visita, también funciona sin conexión.

Abrir el bloc de notas

Funciones

  • Edición de texto sin formato con recuento de palabras, recuento de caracteres y posición del cursor.
  • Abre y guarda archivos de texto en tu dispositivo, o suelta un archivo en la página para abrirlo.
  • Buscar y reemplazar, con distinción de mayúsculas y expresiones regulares.
  • Sintaxis: resaltado de solo lectura para JavaScript, Python, HTML, CSS, JSON, SQL, shell, C y Markdown.
  • Markdown: una vista previa con formato y de solo lectura, con tablas, listas de tareas y bloques de código. El visor de Markdown abre los archivos directamente en esta vista.
  • Modo de bloqueo, que protege el texto de ediciones accidentales.
  • Recientes: las notas de las pestañas cerradas se pueden volver a abrir desde la barra de herramientas.
  • Temas claro y oscuro, zoom y ajuste de línea.
  • Se puede instalar como aplicación y usar sin conexión a internet.
  • Interfaz en 15 idiomas.

Dónde se guardan tus notas

Tu texto se queda en tu dispositivo. Mientras escribes, el texto y el nombre del archivo de la pestaña actual se copian en el sessionStorage de esa pestaña para que sobrevivan a una recarga accidental, y una pestaña nueva siempre empieza vacía. También se guarda una copia de cada nota en el localStorage del navegador; así, cuando cierras una pestaña, su nota aparece en Recientes en la barra de herramientas, donde puedes volver a abrirla o eliminarla. Se guardan hasta 30 notas, y puedes desactivarlo en el mismo menú. Las preferencias de tema, idioma, zoom y ajuste de línea también se guardan en el localStorage. Nada se sincroniza entre dispositivos; para conservar una nota para siempre, guárdala en un archivo con Ctrl+S. La política de privacidad (en inglés) tiene los detalles.

Abrir y guardar archivos

Ctrl+O abre un archivo de texto de tu dispositivo y Ctrl+S lo guarda. En Chrome, Edge y otros navegadores de escritorio basados en Chromium, guardar escribe en el mismo archivo que abriste, después de que el navegador pida permiso. En los navegadores sin esta función, como Firefox y Safari, guardar descarga una copia.

Vista previa de Markdown y resaltado de sintaxis

La vista Markdown (Alt+M) muestra la nota como un documento con formato. Admite GitHub Flavored Markdown: tablas, listas de tareas y bloques de código delimitados, con resaltado. La vista previa se genera en tu dispositivo y el HTML resultante se sanea. Si una nota incluye una imagen de otro sitio web, tu navegador la solicita a ese sitio.

La vista Sintaxis (Ctrl+Shift+H) colorea código en JavaScript, Python, HTML, CSS, JSON, SQL, shell, C y Markdown. El lenguaje se detecta por la extensión del archivo o por el contenido. Las dos vistas son de solo lectura: el texto se bloquea mientras una vista está abierta, y al desbloquearlo vuelves a la edición.

Buscar y reemplazar

Ctrl+F abre la barra de búsqueda. Puedes distinguir mayúsculas, buscar con una expresión regular, reemplazar una coincidencia o reemplazarlas todas. Enter va a la siguiente coincidencia y Shift+Enter a la anterior. En las vistas Sintaxis y Markdown, la búsqueda recorre el texto mostrado y resalta las coincidencias.

Modo de bloqueo

Ctrl+Shift+L bloquea el texto: escribir, pegar, reemplazar y borrar quedan impedidos hasta que lo desbloquees. Pulsar Esc tres veces con el texto bloqueado lo desbloquea y lo borra.

Uso sin conexión e instalación

Después de la primera visita, el navegador guarda una copia de la aplicación, así que se abre sin conexión a internet. En Chrome y Edge puedes instalarla desde la opción de instalación de la barra de direcciones o del menú del navegador. En iPhone y iPad, usa Compartir y luego Añadir a la pantalla de inicio.

Limitaciones

  • Sin sincronización, copia de seguridad en la nube ni enlaces para compartir.
  • Un documento por pestaña. Las notas cerradas solo se guardan en este navegador, hasta 30.
  • Las vistas Sintaxis y Markdown son para leer, no para editar.
  • Necesita un navegador moderno con JavaScript activado.

Preguntas frecuentes

¿Quick Web Notepad es gratis?

Sí. Es de uso gratuito, no tiene plan de pago y el código fuente se publica con la licencia MIT. El sitio muestra anuncios de Google AdSense, incluida una franja fina debajo del editor.

¿Necesito una cuenta?

No. No hay registro ni inicio de sesión.

¿Mis notas se suben o se guardan en un servidor?

No. La aplicación funciona sin servidor: tu texto se procesa en el navegador y se queda en tu dispositivo.

¿Qué pasa con mi texto cuando cierro la pestaña?

Se queda en este dispositivo. Las notas cerradas aparecen en Recientes, donde puedes volver a abrirlas o eliminarlas; una pestaña nueva sigue empezando vacía. Nada se sincroniza con otros dispositivos; para conservar una nota para siempre, guárdala en un archivo con Ctrl+S.

¿Funciona sin conexión?

Sí. Después de la primera visita, el navegador guarda la aplicación en caché y se abre sin conexión a internet. También se puede instalar como aplicación desde la opción de instalación del navegador.

¿Puede guardar en el mismo archivo?

Sí, en los navegadores compatibles con la File System Access API, como Chrome y Edge de escritorio. En otros navegadores, como Firefox y Safari, guardar descarga una copia del archivo.

¿Puede previsualizar Markdown?

Sí. Pulsa Alt+M o el botón Markdown para ver una vista previa de solo lectura con tablas, listas de tareas y bloques de código resaltados. La vista previa se genera en tu dispositivo. Para leer archivos .md, el visor de Markdown muestra con formato al instante cada archivo que abres, sueltas o pegas.

¿Se parece al Bloc de notas de Windows?

Sí, en lo esencial: texto sin formato, abrir y guardar archivos .txt, y buscar y reemplazar. Funciona en el navegador, así que sirve en cualquier sistema sin instalar nada, y añade tema oscuro, vista previa de Markdown y resaltado de sintaxis.

¿Funciona en móviles y tabletas?

Sí. En pantallas pequeñas, la barra de herramientas muestra solo iconos y ocupa más de una línea.

¿En qué idiomas está disponible la interfaz?

Inglés, español, chino, hindi, árabe, francés, portugués, indonesio, vietnamita, turco, tailandés, alemán, japonés, coreano y ruso.

Quién lo hace

Quick Web Notepad lo crea OFCode-dev como una pequeña herramienta web independiente. Está hecho con HTML, CSS y JavaScript sin framework ni paso de compilación. La vista Markdown usa las bibliotecas de código abierto marked y DOMPurify, que se sirven desde este sitio. El código fuente está en GitHub con la licencia MIT.
